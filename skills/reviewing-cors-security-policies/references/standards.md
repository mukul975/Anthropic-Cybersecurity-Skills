# Standards and References — Reviewing CORS Security Policies

## NIST CSF 2.0

| ID | Name | Rationale |
|----|------|-----------|
| DE.CM-01 | Networks and network services are monitored to find potentially adverse events | Continuous monitoring and proactive review help identify configuration drift and vulnerability vectors. |
| RS.AN-01 | Incidents are analyzed to determine attack targets and root cause | Reviewing code and traffic patterns establishes baseline defense requirements against exploit attempts. |

## MITRE ATT&CK

| Technique ID | Name | Tactic | Rationale |
|--------------|------|--------|-----------|
| T1189 | Vulnerability Scanning / Review | Reconnaissance / Initial Access | Proactive identification and verification of security weaknesses across application boundaries. |
